# आँगन • Aangan

A quiet digital courtyard.

A soft place to sit when the world feels a little too loud.

No accounts. No likes. No noise.  
Just a quiet space, a diya you can light, and the soft sense that others are also sitting somewhere nearby.

---

### How to run

1. Download `aangan-bg.jpg` (the courtyard image) and place it next to `index.html`
2. Open `index.html` in a browser

Or deploy the folder to Vercel / Netlify / GitHub Pages.

Made with care.
